# Trading Toolkit

Trading Toolkit is a Python command-line application designed to help forex traders perform important trading calculations quickly and accurately.

## Features
- 📊 Pip Calculator
- 💰 Risk Calculator
- 📏 Position Size Calculator
- 🛑 Stop Loss Calculator
- 🖥️ Simple and beginner-friendly menu interface

## Technologies Used
- Python 3

## Purpose
This project was created to improve my Python programming skills while building practical tools that can be useful for beginner and experienced forex traders.
